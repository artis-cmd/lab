💡 서버 실행 확인:

  • 위의 상태 표시가 🟢 온라인으로 바뀌면 성공!
  • 브라우저에서 http://localhost:8003 접속 가능 (새 창으로 열기)
  • API 문서: http://localhost:8003/docs (새 창으로 열기)
  • 서버 중지: 터미널에서 Ctrl+C

🎯 2단계: 시스템 사용

  1. 파일명 도구에서 차트 이미지를 선택하고 "artisAsset에 저장" 버튼을 클릭
  2. 대시보드에서 "분석 실행" 버튼을 클릭하여 AI 분석 시작
  3. 분석 완료 후 생성된 리포트를 확인
