🎯 1. 시스템 개요

artisAsset은 Google Vision API와 Gemini API를 활용하여 트레이딩 차트를 자동으로 분석하고 전문적인 리포트를 생성하는 AI 시스템입니다.

💡 "분석 대기"란?

"AI 분석을 기다리고 있는 차트 이미지들"을 의미합니다. 파일명 도구에서 업로드한 차트 이미지들이 여기에 표시되며, "🚀 분석 실행" 버튼을 누르면 이 파일들이 분석됩니다.

  • 위치: artisAsset/data/input/charts/ 폴더
  • 파일 형식: PNG, JPG, JPEG, BMP, TIFF
  • 상태: AI 분석 대기 중
  • 기능: 파일 목록 표시, 크기/날짜 정보, 개별 삭제, 업로드

📊 분석 완료

  • 의미: AI 분석이 완료되어 리포트가 생성된 파일들
  • 위치: artisAsset/data/output/reports/ 폴더
  • 파일 형식: Markdown (.md) 리포트 파일
  • 버전 관리: v1, v2, v3... 형태로 버전별 보존
  • 기능: 👁️ 리포트 보기 🖼️ 이미지 보기 🔄 재분석 🗑️ 삭제

📈 분석 이력 섹션

  • 타임라인 표시: 시간순으로 분석 작업 이력 표시
  • 필터링: 날짜별, 상태별 필터링 가능
  • 상태 구분: 완료 처리중 오류

🔄 3. 사용 워크플로우

📝 파일명 생성 및 업로드

[파일명 도구] → 차트 이미지 선택 → "🚀 artisAsset에 저장" → [🔍 분석 대기]에 표시
  • 파일명 도구에서 표준화된 파일명 생성
  • 차트 이미지 선택 후 "artisAsset에 저장" 버튼 클릭
  • Live Dashboard의 "분석 대기" 섹션에서 업로드된 파일 확인
  • 체크박스 선택: 분석할 파일들을 체크박스로 선택

🚀 선택적 AI 분석 실행

[체크박스 선택] → [🚀 선택된 N개 파일 분석] 클릭 → AI가 선택된 차트만 분석
  • 선택적 분석: 체크된 파일들만 분석 (전체 또는 일부)
  • 스마트 버튼: 선택된 파일 수에 따라 버튼 텍스트 변경
  • Google Vision API로 차트 이미지에서 텍스트 및 패턴 추출
  • Google Gemini API로 전문적인 트레이딩 분석 수행
  • 분석 진행 상황을 실시간으로 모니터링
  • 버전 관리: 새로운 분석 결과는 v1, v2, v3... 형태로 저장

📊 다양한 방식으로 결과 확인

분석 완료 → [📊 분석 완료]에 리포트 생성 → 👁️🖼️🔄 버튼으로 다양한 액션
  • 분석 완료 시 WebSocket을 통한 실시간 알림
  • "분석 완료" 섹션에서 생성된 리포트 확인
  • 👁️ 리포트 보기: AI 분석 결과 상세 내용 확인
  • 🖼️ 이미지 보기: 원본 차트 이미지를 크고 선명하게 확인
  • 🔄 재분석: 해당 파일만 다시 분석 (새 버전 생성)
  • 🗑️ 삭제: 불필요한 리포트 삭제
  • 분석 이력 및 통계에서 전체 현황 파악

📈 실시간 모니터링

WebSocket으로 실시간 알림 → 분석 완료 시 자동 갱신
  • WebSocket 연결을 통한 실시간 상태 업데이트
  • 분석 완료, 에러 발생 시 즉시 알림
  • 필요시 자동 갱신 설정으로 정기적 모니터링

🛠️ 5. 문제 해결

🔴 서버 연결 문제

증상: "artisAsset 서버 오프라인" 표시

  1. artisAsset 서버가 실행 중인지 확인
  2. python dashboard_server.py 또는 start_server.bat 실행
  3. 포트 8003이 사용 중인지 확인
  4. 방화벽 설정 확인

📤 파일 업로드 실패

증상: "업로드에 실패했습니다" 메시지

  1. 파일 형식 확인 (PNG, JPG, JPEG, BMP, TIFF)
  2. 파일 크기 확인 (10MB 이하)
  3. artisAsset/data/input/charts 폴더 권한 확인
  4. 서버 재시작

🤖 분석 실패

증상: 분석이 완료되지 않거나 에러 발생

  1. Google API 키 설정 확인
  2. .env 파일의 API 키 유효성 확인
  3. 인터넷 연결 상태 확인
  4. 서버 로그에서 자세한 에러 메시지 확인

🚨 API 할당량 초과 (신규)

증상: "429 You exceeded your current quota" 에러

원인: Google Gemini API 무료 할당량 초과 또는 결제 계정 미연결

  1. 새 API 키 생성: Google AI Studio에서 새로운 프로젝트로 API 키 생성
  2. 결제 계정 연결: Google Cloud Console에서 프로젝트에 결제 계정 연결
  3. 할당량 증가 요청: Google Cloud Platform에서 할당량 증가 신청
  4. 환경변수 업데이트: .env 파일에서 GOOGLE_GEMINI_API_KEY 교체
  5. 서버 재시작: 새로운 API 키 적용을 위해 서버 완전 재시작

참고: 할당량 증가 승인까지 1-3일 소요, 기본 분석은 계속 가능

🔧 포트 충돌 해결 (신규)

증상: "error while attempting to bind on address" 에러

  1. 포트 사용 확인: netstat -ano | findstr :8003
  2. 프로세스 종료: taskkill /f /im python.exe
  3. 서버 재시작: start_server.bat 다시 실행
  4. 포트 변경: dashboard_server.py에서 포트 번호 수정 (현재: 8003)
