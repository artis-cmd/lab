템플릿 상태: 미확인

📋 참고사항

  • 날짜는 YYYYMMDD 형식으로 입력되며, 자동으로 요일 정보(a=월요일, b=화요일, c=수요일, d=목요일, e=금요일, f=토요일, g=일요일)가 추가됩니다.
  • L1 레이아웃은 '1시간/15분/5분/1분 4분할 차트'를 의미합니다.
  • 시장 세션은 선택 시 파일명에 약자(TK, LD, NY)로 포함됩니다.
  • 매매 단계는 선택 시 파일명에 복기, 진입전, 매매중, 결제후 형태로 포함됩니다.
  • 매매 방향은 선택 시 파일명에 _Buy, _Sell, _Range 형태로 포함됩니다.
  • 사용툴은 선택 시 파일명에 _FT5, _TV, _MT4 형태로 포함됩니다.
  • 매매 이력은 선택 시 파일명에 _tR0(없음), _tR1(있음) 형태로 포함됩니다.
  • 분석 내용은 입력된 내용들을 언더바(_)로 연결합니다. (예: 지지선돌파_강한상승_매수시점)
  • 모든 필드를 채우지 않아도 파일명은 생성되지만, 명확한 복기를 위해 모든 정보를 입력하는 것을 권장합니다.
  • 리포트 템플릿은 차트 분석 시 생성되는 리포트의 구조를 정의합니다. JSON 형식으로 섹션과 항목을 설정할 수 있습니다.
