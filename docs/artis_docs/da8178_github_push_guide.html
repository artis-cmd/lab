📁 HTML 프로젝트 GitHub 푸시

1단계: GitHub 저장소 생성

GitHub에서 새 저장소를 생성합니다:

  • 저장소 이름: html-trading-tools
  • 설명: 트레이딩 도구 및 artisAsset 연동 HTML 프로젝트
  • Public 또는 Private 선택
  • README, .gitignore, license 추가하지 않음

2단계: 원격 저장소 연결

생성된 GitHub 저장소 URL을 복사하고 연결합니다:

git remote add origin https://github.com/[사용자명]/html-trading-tools.git

3단계: 메인 브랜치로 푸시

현재 커밋을 GitHub에 푸시합니다:

git branch -M main
git push -u origin main
✅ HTML 프로젝트 백업 완료!
모든 파일이 GitHub에 성공적으로 업로드되었습니다.

🤖 artisAsset 프로젝트 GitHub 푸시

1단계: artisAsset 디렉토리로 이동

cd "E:\GoogleDrive\My Drive\artisAsset"

2단계: Git 저장소 초기화

git init
git add .
git commit -m "artisAsset 트레이딩 차트 분석 시스템 초기 커밋"

3단계: GitHub 저장소 생성 및 연결

GitHub에서 새 저장소 생성:

  • 저장소 이름: artisasset-trading-system
  • 설명: AI 기반 트레이딩 차트 분석 시스템
  • Private 권장 (API 키 포함)
git remote add origin https://github.com/[사용자명]/artisasset-trading-system.git
git branch -M main
git push -u origin main
⚠️ 주의사항:
• .env 파일에 API 키가 포함되어 있으므로 Private 저장소 사용 권장
• 필요시 .gitignore에 .env 추가 고려

🔧 자주 발생하는 문제 해결

문제 1: "fatal: bad object HEAD" 오류

해결방법:

Remove-Item -Recurse -Force .git
git init
git add .
git commit -m "프로젝트 초기 커밋"

문제 2: "fatal: could not parse HEAD" 오류

해결방법:

git checkout --orphan new-branch
git add .
git commit -m "새 브랜치로 초기 커밋"
git branch -D main
git branch -m main

문제 3: PowerShell에서 && 연산자 오류

해결방법: PowerShell에서는 ; 사용

# 잘못된 방법
git add . && git commit -m "메시지"

# 올바른 방법
git add .; git commit -m "메시지"

문제 4: 인증 오류

해결방법:

  • GitHub Personal Access Token 사용
  • Git Credential Manager 설치
  • SSH 키 설정

GitHub에서 확인할 사항

✅ 저장소 생성 후 확인사항:

  • 저장소 이름: 정확한 이름으로 생성되었는지 확인
  • 설명: 프로젝트 설명이 올바르게 표시되는지 확인
  • Public/Private: 설정한 가시성이 올바른지 확인
  • README: 자동 생성되지 않았는지 확인 (수동으로 생성하지 않았으므로)

✅ 푸시 완료 후 확인사항:

  • 파일 업로드: 모든 파일이 정상적으로 업로드되었는지 확인
  • 폴더 구조: 로컬과 동일한 폴더 구조인지 확인
  • 커밋 히스토리: 커밋 메시지가 올바르게 표시되는지 확인
  • 브랜치: main 브랜치가 기본 브랜치로 설정되었는지 확인
